# 自然语言处理课程实验：通用提示词模板（第六周及以后可复用）

使用时请把方括号里的内容改成当周信息，整段复制给助手即可。

## 可复制提示词正文

我有一份自然语言处理课程实验任务书，路径为【当周请填写任务书 PDF 或文档的完整路径】。请按任务书完成本次实验。

**工作范围**

- 我只需要你完成**代码与数据文件**的编写与整理；我会在本机虚拟环境中自行安装依赖并运行，你不必代替我执行运行命令（若环境允许、你也可自测，但不强求）。
- 实验报告中的**文字部分**（回答问题、实验简述等）若我另行索要，请你根据我提供的**程序运行输出**来写，不要编造未出现的数值。

**与往届实验对齐**

- 请参考仓库内「自然语言处理作业」目录下**前几周实验**的目录命名、数据文件命名（如 `exp-x.y-data.txt`）、以及 Python 脚本风格：文件头编码声明、数据路径常量、`main` 与 `if __name__ == "__main__"`、分区打印标题等，与最近一周（如第四周、第五周）保持一致即可。

**任务书层面通常需要覆盖的内容（以当周 PDF 为准）**

- 按任务书实现各小实验的**环境说明**中所列依赖能支撑的程序逻辑。
- **实验数据**：若任务书给了示例句或语料，应用独立数据文件或代码内清晰可改的配置保存，便于复现。
- **实验步骤**：分步在代码或输出中可对应（输入、处理、输出结果）。
- **实验结果分析**：任务书若列出思考题，我可能会根据运行结果请你代写答案；见下文写作格式要求。

**代码与实现注意**

- 中文文本若使用 `sklearn` 的 `TfidfVectorizer` 等，对已用分词工具按空格拼接的文档，需避免默认 `token_pattern` 丢掉单字词导致相似度全为零等问题；实现以可复现为优先。
- 控制台输出应便于我**截图**写入报告（结构清晰、关键数字与标签齐全）。
- 不要擅自扩大范围：除非任务书或我明确要求，不额外写 README、不批量改无关文件。

**当我请你写实验报告相关文字时，请遵守**

- 全文使用**简体中文**。
- 若回答任务书思考题：采用**先写问题、再写对应答案**的对应关系，便于我核对；每个问题单独成段或问题行与答案行分明。
- 报告正文与代写答案中**不要使用**直角引号「」、箭头、加号等装饰性或易与排版冲突的符号；用逗号、句号与常规括号即可。
- 若我要求精简，则**缩短篇幅**，保留与结果直接相关的结论。
- **实验简述**（每个实验一段话即可）：只陈述**本次具体做了什么、程序是否跑通并得到预期输出**，不要写学会了什么、为今后奠定基础等空话套话。

**提交类信息**

- 若任务书写明收件邮箱、邮件标题格式、是否合并为一个 PDF 等，请你在我整理邮件或报告目录时**提醒我引用任务书原文**，不要凭记忆改邮箱或学号格式。

## 第五周任务书衍生的条目速查（供对照，以后周次以新任务书为准）

以下由《自然语言处理第五周实验任务书》归纳，便于你理解上述模板从哪类文件抽象而来。

**实验九（篇章连贯性）**

- 名称要点：句子顺序与上下文一致性分析。
- 环境与工具：Python 3.8 以上，Jupyter 或脚本均可；jieba；sklearn 可选（可作相似度辅助）。
- 数据与操作：给定连贯三句与打乱版本，另有天气散步买书示例需打乱；构造连贯与非连贯文本，分析顺序变化，**相邻句相似度**，据此讨论连贯性。
- 步骤链条：输入原文、构造乱序、分词、算相邻句相似度、对比不同顺序、判断并分析。
- 报告需回应的分析题五道：原序与乱序连贯性差异、顺序为何影响理解、相邻相似度能否反映连贯、是否存在语义相关但不连贯、篇章相对句子的额外挑战。
- 正式报告结构（任务书）：实验目的、原理、步骤与代码、结果截图、结果分析、总结。

**实验十（指代消解）**

- 环境与工具：Python 3.8 以上；jieba 可选；re 用于规则；进阶可选 hanlp、spacy。
- 数据：四条关于小明小红老师学生的短文。
- 内容与步骤：分句、标实体、找代词、按上下文规则（如最近实体）匹配、输出指代关系、标歧义、整理分析。
- 报告需回应的分析题四道：各代词指向、哪些句有歧义、为何局部信息不够、上下文起何作用。
- 正式报告结构：同上；任务书另要求邮件标题与收件人、PDF 与多份报告合并发送等（以 PDF 原文为准）。

## 使用方式建议

1. 新开一周实验时，复制「可复制提示词正文」一节。
2. 将首句中的路径改为当周任务书路径。
3. 若当周只需代码，可删掉「当我请你写实验报告相关文字时」整段；若需要代写思考题，把该段保留并附上你的运行输出粘贴。
